# Runway

Runway is a personal web app that reads a fixed weekly schedule from Google Calendar and breaks assignments into steps with AI. It spreads those steps across free time as study blocks and re-plans nightly from a short check-in.

## Tech stack

- Next.js with TypeScript and the App Router
- Tailwind CSS and shadcn/ui
- Supabase
- Google Calendar API
- OpenAI API
- Vercel
- Resend

Personal project in active development.
